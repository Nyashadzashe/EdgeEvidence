# EdgeEvidence

EdgeEvidence is a Raspberry Pi-based digital forensic readiness prototype for edge networks.

## Features
- Continuous network packet capture
- SHA-256 hashing of completed capture files
- Evidence manifest and integrity verification
- Google Drive evidence-upload prototype
- Web dashboard prototype

## Platform
- Raspberry Pi OS
- Wireshark dumpcap
- Python
- React and Vite

## Status
Prototype under development. Validate the evidence-handling pipeline before production use.

## Security
Credentials, packet captures, and local evidence are excluded from version control.
